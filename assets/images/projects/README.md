# Project Images

هذا المجلد يحتوي على صور المشاريع لاستخدامها في:
- بطاقات المشاريع
- Open Graph meta tags
- Twitter Cards
- المشاركة الاجتماعية

## الصور المطلوبة

كل مشروع يحتاج صورة بتنسيق `.webp` أو `.png`:

- spleeter.webp
- demucs.webp
- open-unmix.webp
- audio-separator.webp
- silero-vad.webp
- speechbrain-vad.webp
- xtts-v2.webp
- deoldify.webp

## المواصفات المقترحة

- **الأبعاد:** 1200x630 (مناسبة لـ Open Graph)
- **الحجم:** أقل من 100KB
- **التنسيق:** WebP (أو PNG كخيار بديل)
- **الخلفية:** متوافقة مع تصميم الموقع

## ملاحظة

حاليًا الصور غير متوفرة. يمكن استخدام placeholder مؤقتًا أو شعار المشروع الأصلي.
